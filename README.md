# Women's Safety App: She 🚨

An Android-based women’s safety application developed using **Java** and **Firebase** to provide quick emergency assistance and improve personal security through smart mobile features.

## ✨ Features

- 🚨 One-tap SOS emergency alerts  
- 📍 Real-time live location sharing  
- 👥 Trusted contact management  
- 🔐 Secure Firebase authentication  
- ☁️ Cloud database integration  
- 📱 Clean and user-friendly interface  

## 🛠️ Tech Stack

- **Language:** Java  
- **Platform:** Android Studio  
- **Backend:** Firebase  
- **Database:** Firebase Realtime Database / Firestore  

## 🎯 Project Purpose

Developed as a **3rd-year academic project** focused on creating a practical safety solution for women using modern mobile technologies.

## 📚 Skills Gained

- Android App Development  
- Firebase Integration  
- Software Development Life Cycle (SDLC)  
- Software Project Management  
- UI/UX Design Principles
